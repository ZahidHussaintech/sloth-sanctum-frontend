# Sloth Sanctum - Front-End Web Architecture

A multi-page responsive static website built with semantic HTML5 and vanilla CSS3, showcasing layout design, typography handling, and form integration.

## Key Highlights
- **Semantic Structure:** Fully structured navigation headers, hero showcases, table schedules, and contact form inputs.
- **CSS Flexbox Architecture:** Responsive navigation bars, multi-column alignment, and flexible image gallery grids.
- **Custom Web Typography:** Embedded local font assets (`jungle.ttf`) with robust fallback font families.
- **Multi-Page Journey:** Separate dedicated interfaces for Home (`index.html`) and Contact Inquiry (`contact.html`).

## Directory Overview
- `practice/`: HTML source files for site pages and responsive layout modules.
- `css/`: Modular stylesheets for main home layout and contact pages.
- `fonts/`: Embedded custom web fonts.
- `images/`: Visual assets, branding logos, and content photography.
