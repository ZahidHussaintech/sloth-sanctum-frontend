# Sloth Sanctum - Front-End Web Architecture

A multi-page responsive static website built with semantic HTML5 and vanilla CSS3, created as part of practical front-end mastery.

## Key Features
- **Semantic HTML5:** Structured navigation, hero showcase, data tables, and input forms.
- **CSS Layout Architecture:** Utilizes CSS Flexbox for navigation flow, responsive gallery alignments, and operating hour schedules.
- **Custom Typography:** Integrated local web fonts (`jungle.ttf`) with fallback font stacks.
- **Multi-Page Flow:** Includes Home (`index.html`) and Contact Inquiry (`contact.html`) interfaces.

## Project Structure
- `practice/`: HTML source files for site pages and flexbox layout practice.
- `css/`: Dedicated stylesheets for home and contact pages.
- `fonts/`: Custom web fonts and assets.
- `images/`: Optimized visual assets and icons.
